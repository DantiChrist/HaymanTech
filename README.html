Business Overview

HaymanTech is a local IT support provider for Brisbane South (Macgregor, Sunnybank, Mt Gravatt). The brand distinguishes itself through empathy and communication skills derived from 15 years in hospitality, backed by enterprise engineering experience.

Core Philosophy "Keep It Simple." No geek-speak, transparent pricing.
Mascot Athena (The loyal dog). Represents patience and loyalty.
Target Audience Seniors, Families, Remote Workers, Small Biz (1-20 staff).

Website Architecture

The website utilizes a "No-Backend" architecture to reduce hosting costs and complexity. It relies on client-side logic for all interactivity.

Tech Stack

  • HTML5: Semantic static structure.
  • Tailwind CSS: Loaded via CDN for rapid development and consistent design system.
  • Phosphor Icons: Lightweight, clean SVG icon library.
  • Canvas Confetti: JS library for the "Success" animation in Athena AI.

Athena AI Logic Engine

Athena is a client-side JavaScript decision tree engine (`DECISION_TREE` object) found in athena_ai.html. She does not use Generative AI to ensure safety and accuracy.

1. Network Diagnostics

Checks for APIPA (169.254.x.x) -> Prescribes Router Reboot.
Checks for DNS failures (1.1.1.1 check) -> Prescribes ipconfig /flushdns.

2. Printer Troubleshooting

Identifies "WSD Port" trap -> Forces switch to TCP/IP Port.

3. Victory Verification

Includes a VERIFY_FIX node. Athena never declares success until the user confirms the issue is resolved.

Key Implementations

SMS "Quick Message"

Located in index.html. Instead of a server sending emails, JavaScript captures input and opens the native SMS app using the sms:0477...?body= protocol. Zero spam filters, instant delivery.

Remote Modal

A popup modal that triggers the direct download of the RustDesk installer (.msi) from GitHub.

Mobile Viewport Fix

Uses interactive-widget=resizes-content in meta tags to ensure the iOS keyboard doesn't cover Athena's chat input.
